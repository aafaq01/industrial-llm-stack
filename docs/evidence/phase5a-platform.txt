== 4. ArgoCD git source (no remote)
ArgoCD reads git://kind-git/industrial-llm-platform (branch main): a git daemon container (infra/git-server) on the
kind Docker network serving .tools/git/industrial-llm-platform.git read-only. kind-up.sh pushes either the committed
HEAD (GIT_SOURCE=head, now the default) or a synthetic snapshot commit of the working tree (GIT_SOURCE=worktree,
opt-in; it includes untracked files, is not in the repo history, and its objects stay in .git/objects until git gc
prunes them). All runs in this file used worktree, which was the default when they ran, because Phase 5a was not
committed; the REVISION column in section 3 is such a snapshot commit. Limitation: ArgoCD sees only what kind-up.sh
last published, never live edits. Expected follow-up after the 5a commit: GIT_SOURCE=head bash scripts/kind-up.sh.
